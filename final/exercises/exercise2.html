Exercise F2: Model Finetuning (Week 15)

  • Throughout this exericse, I learned how to implement a tokenizer in a selected pre-trained BERT model to leverage its existing language understanding for a Question and Answering task. Using the Hugging Face Transformers library, I loaded both the BERT tokenizer and the model specifically tailored for Q&A. These components are essential for converting raw text into token representations and for enabling BERT to understand context and accurately predict answer spans.
  • I also learned how to identify the character-level start and end indices of answer text within the context paragraph, which is crucial for supervised training in Question and Answering tasks. By creating a helper function named add_answer_position, I implemented case-sensitive matching between the answer and the context, defaulting to zero if the answer was not found. This process aligned ground truth answers to their correct positions, enabling the model to efficiently and accurately learn to predict answer spans.
  • Then, I reloaded the model onto the computational device, using a GPU when available to ensure faster training and inferece. This stage made me realize the importance of properly managing computational resources such as GPU, CPU, and RAM. This step taught me that efficient deployment and veritifcation are crucial in machine learning workflows, as they directly impact performance and reliability. Learning this strengthened my practical skills in preparing models for production.
  • Designing a robust training and evaluation frameword for a Question and Answering model, are one of the things I discovered. It's ensuring both reproducibility and thorough performance assessment. Setting controlled experimental conditions, such as explicit random seeds across Python, NumPy, and PyTorch (including the CUDA operations), taught me how critical reproducibility is in machine learning experiments. I also learned to define evaluation metrics aligned with Q&A objectives and to select training hyperparameters that balance accuracy and computational efficiency. Leveraging automated training APIs further helped me streamline model optimization, monitor performance systematically, and select the best-performing model.
